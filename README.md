# Roldan Palaña Portfolio

A modern, dark-themed portfolio website showcasing the skills, experience, and projects of Roldan Palaña, an IT graduate and web developer.

## Features

- **Responsive Design**: Optimized for all devices
- **Dark Theme**: Sleek and modern aesthetic
- **Interactive Elements**: Animated backgrounds, hover effects, and ripple interactions
- **Skills Showcase**: Visual representation of technical skills
- **Contact Information**: Easy access to contact details

## Technologies Used

- HTML5
- CSS3 (with animations and transitions)
- JavaScript (for dynamic effects)

## Sections

- **About Me**: Introduction and background
- **Skills**: Technical proficiencies with icons
- **Languages**: Language proficiency bars
- **Experience**: Work history
- **Education**: Academic background
- **Contact**: Contact information

## Live Demo

View the live portfolio at: [https://roldan-s-palana.github.io/Web-Resume/](https://roldan-s-palana.github.io/Web-Resume/)
